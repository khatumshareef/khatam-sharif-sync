# Khatam Sharif Sync

Create a modern, elegant, and responsive web application named "Khatam Sharif" for interactive Quran recitation synchronization.

Key Requirements & Specifications:

1. App Name & Branding:

   - Name: Khatam Sharif

   - Provide a clean header with placeholder space for the Logo and Audio File Uploader/Selector.

   - Design: Elegant Islamic aesthetics (dark mode by default or clean modern emerald green & gold/white theme), RTL support for Arabic text, fully responsive for Mobile and Desktop.

2. Source of Truth (Word Timestamps):

   - The app MUST NOT estimate, guess, or auto-generate timestamps.

   - Use the embedded JSON dataset below as the STRICT source of truth for all words, their order, and exact start/end timestamps.

3. Core Features:

   - Interactive Arabic Text Display: Render Arabic words in large, clear Quranic font (e.g., Scheherazade New or Amiri), styled with proper spacing and RTL layout.

   - Live Word Highlighting: When the audio/video plays, highlight the EXACT active word in real-time based on `start` and `end` times.

   - Smooth Auto-scroll: Automatically scroll the page/container to keep the currently reciting word in the center view of the screen.

   - Click-to-Seek / Jump: Clicking on any Arabic word should immediately seek/jump the audio player to that word's exact `start` time and start playing.

   - Full Media Controls: Custom sticky player bar with Play/Pause, Progress Seekbar, Time display (Current/Total), Playback Speed Controls (0.5x, 0.75x, 1x, 1.25x, 1.5x), and Ayah/Section Navigation.

   - Media Support: Support uploading custom MP3/M4A/WAV or MP4 video files locally, or fallback to a default audio player using the timestamps.

بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ

هُوَ اللَّهُ الَّذِي لَا إِلَٰهَ إِلَّا هُوَ ۖ عَالِمُ الْغَيْبِ وَالشَّهَادَةِ ۖ هُوَ الرَّحْمَٰنُ الرَّحِيمُ
